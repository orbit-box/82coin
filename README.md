# 82coin

실시간 암호화폐 시장정보 중심 무료 커뮤니티 플랫폼 — MVP v0.1.

## 메뉴
- 홈
- 시장정보 (실시간 시세·김치프리미엄 참고 값)
- 커뮤니티 (초기 UI)
- 혜택 (제휴 검토 중 안내)

## 실행
Node.js 20 이상 환경에서:

```bash
npm install
npm run dev
```

`http://localhost:3000`에 접속합니다.

## 주의사항
- Upbit, Binance, 환율 API에 접근할 수 있어야 시세가 보입니다.
- 가격과 김치프리미엄은 참고용이며, 거래소·환율 갱신 시점의 차이와 USDT/USD 차이로 오차가 생길 수 있습니다.
- 뉴스·경제 일정, 로그인, 저장형 게시판, 관리자, 레퍼럴/페이백은 이번 커밋에 포함되지 않습니다. 앞으로 개발합니다.
- 레퍼럴·페이백은 별도 법률·제휴 검토를 거쳐 활성화합니다.
- 현재 운영 준비 전의 개발 버전으로, 라이브 서비스가 아닙니다.
